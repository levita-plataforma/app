# Seguridad, emergencias y primeros auxilios

## Objetivo
Coordinar voluntarios y responsables que protegen la operación del edificio y responden ante incidencias sin convertir LEVITA en sistema de emergencias profesional.

## Puestos habituales
- responsable de seguridad;
- apoyo de evacuación;
- primeros auxilios;
- control de accesos;
- responsable de incidencias.

## Requisitos
- criticidad alta;
- cualificaciones/credenciales configurables;
- cobertura mínima;
- teléfono interno visible solo a autorizados;
- plan/documentos de emergencia como archivos restringidos;
- registro de incidencias separado de notas generales;
- comunicación urgente.

## Reglas
Una iglesia puede no tener esta área. Las funciones críticas deben poder asociarse a una actividad o a una franja de apertura del edificio. No guardar datos médicos de asistentes salvo necesidad y base adecuadas.
