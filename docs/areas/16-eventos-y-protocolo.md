# Eventos, protocolo y producción

## Objetivo
Coordinar conferencias, retiros, celebraciones, bodas u otros actos que necesitan varios equipos y recursos.

## Roles posibles
- dirección de evento;
- protocolo;
- acreditación;
- producción;
- escenario;
- montaje;
- invitados;
- hospitality;
- coordinación técnica.

## Necesidades
- Activity/Event como raíz;
- múltiples áreas;
- recursos y salas;
- formularios/inscripciones;
- agenda;
- dependencias;
- tareas sin puesto;
- contactos externos;
- checklists.

## Integración
Events + Serving + Facilities + Communications. Un evento grande no debe modelarse como un único “culto” con cientos de puestos.
